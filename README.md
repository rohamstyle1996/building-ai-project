# Plant Health AI Assistant
Building AI course project

## Summary
An AI-powered mobile tool that detects common plant and crop diseases using smartphone camera images to help farmers reduce crop loss.

## Background
Crop diseases cause massive agricultural loss worldwide, especially for smallholder farmers who lack quick access to agronomists. Early detection allows timely intervention before the disease spreads across entire fields.

## Data and AI techniques
* **Data Sources:** Open-source datasets such as PlantVillage containing thousands of labeled leaf photos.
* **AI Techniques:** Convolutional Neural Networks (CNNs) and transfer learning (e.g., MobileNet) for image classification.

## How is it used
Farmers take a photo of an affected leaf using a mobile app. The AI model analyzes the symptoms and provides an instant diagnosis alongside recommended treatments.

## Challenges
* High sensitivity to image quality, variations in outdoor lighting, and partial leaf occlusions.
* It identifies visible leaf symptoms but cannot detect soil nutrient deficiencies directly.

## What next
Integrating weather forecasts to predict outbreak risks and expanding the database to cover rare localized crop types.
